# Portafolio HTML/CSS — práctica de una página

Ejercicio de curso: una landing de portafolio de una sola página, maquetada
en HTML y CSS puro (sin frameworks ni build step).

## Cómo verla

Abre `index.html` directamente en el navegador, o sirve la carpeta con
cualquier servidor estático:

```bash
python3 -m http.server 8000
```

## Contenido

- `index.html` — la página.
- `css/styles.css`, `css/normalize.css` — estilos.
- `img/` — imágenes usadas en los fondos de sección.

Los enlaces del menú (`Inicio`, `Sobre Mi`, `Clientes`, `Contacto`) son
marcadores de posición (`href="#"`): la página es de una sola pantalla, sin
rutas reales.
